Endpoints

MethodPathDescription
POST /api Generate a new API token
GET /api/todos List your todos
POST /api/todos Create a todo (JSON body: {"title":"..."})
PUT /api/todos/{id} Update a todo (JSON body: {"done":true})
DELETE /api/todos/{id} Delete a todo

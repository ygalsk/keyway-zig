Keyway

A highly opinionated engine with no opinions

HTTP engine powered by Zig, controlled by Lua. You write the logic, Zig handles the rest.

Write Handlers in Lua

Define routes and logic in plain Lua. Change behavior without recompiling. No restarts.

One Core, One Thread, One State

Every CPU core runs its own isolated event loop. No locks, no sharing, no surprises.

Zero-Copy from Kernel to Handler

Request bytes stay in one buffer from recv to response. Parse, route, respond — nothing moves.

The Interface

keyway.routes = {
    ["/users/{id}"] = {
        GET = function(ctx)
            ctx.status = 200
            ctx.headers["Content-Type"] = "application/json"
            ctx.body = '{"id":' .. ctx.params.id .. '}'
        end,
    },
}

No send(). No write(). Set fields on ctx — Lua expresses intent, Zig commits I/O.

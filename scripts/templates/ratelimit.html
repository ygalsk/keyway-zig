Rate Limiter

Sliding window rate limiting with Redis sorted sets and EVAL

How It Works

The endpoint /ratelimit/api is protected by a middleware that uses a Redis sorted-set sliding window. Each request adds a timestamp entry; expired entries are pruned atomically via EVAL. The limit is 10 requests per 60 seconds per client. 

-- Atomic sliding window via Redis EVAL
redis.call("ZREMRANGEBYSCORE", key, 0, now - window)
local count = redis.call("ZCARD", key)
if count < limit then
    redis.call("ZADD", key, now, now .. ":" .. math.random())
    return { 1, limit - count - 1 }
end
return { 0, 0 }
